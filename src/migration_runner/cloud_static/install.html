Infrastructure foundation

This release prepares private hosts and AWS read access. Application installation and credential enrollment are still being built. Downloading a package creates no cloud resources and does not change the running migration environment.

1. Identify the installation

The token authorizes package preparation. It stays in this page's memory and is never included in a download. Do not enter cloud passwords, access keys or private certificates.

2. AWS source

Use a dedicated prefix ending in /. The generated AWS template grants read access; it does not create, delete or upload source objects. Your AWS administrator supplies the deployment's public CA certificate in CloudFormation.

3. OCI destination and network

The stack references your existing network and buckets. Network owners must configure routes, DNS, service access and security lists. A private selection restricts the AWS reader to the specified endpoint; it does not create or verify an interconnect.

4. Private compute

The coordinator adds one E5 instance with 2 OCPUs and 16 GiB. This release supports x86 workers; Ampere packaging is pending. Maximum workers is a configuration boundary, not an automatic scaler or spending cap.

5. Test connections

Check AWS source reads and OCI destination visibility using the source and destination settings above. Compute and network infrastructure fields are not required for this test.

Live checks are disabled on this server. Enable them in the local setup assistant with your existing cloud profiles.
